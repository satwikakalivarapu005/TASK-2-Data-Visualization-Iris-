## Problem Statement
Visualize patterns in the Iris dataset across 3 flower species.

## Dataset
- Name: Iris Dataset
- Source: sklearn.datasets (built-in)
- Rows: 150 | Classes: 3 species

## Key Insights
- Setosa is clearly separable from other species
- Petal length & width are highly correlated (r=0.96)
- Virginica has the largest petal dimensions

## Tools: Python, Pandas, Matplotlib, Seaborn
